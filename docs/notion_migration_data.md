## Migration Instructions

For each ticket below:
1. Create a new entry in your GTM Initiatives database
2. Copy the Initiative name as the title
3. Set the Workstream, Priority, Status, and Track properties
4. Paste the Notes content
5. Add the GitHub Issue URL for reference

After all tickets are in Notion, run the close commands at the bottom.
